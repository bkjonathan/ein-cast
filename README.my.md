# EinCast

*သင့်အိမ်ရှိ မီဒီယာများကို ဖန်သားပြင်တိုင်းတွင်။* "အိမ်" (Ein) ဆိုသည်မှာ ဗမာလို *home* ဟု ဆိုလိုသည်။

> **မူကြမ်း။** ဤစာမျက်နှာကို ဗမာစကားပြောသူ မစစ်ဆေးရသေးပါ။ မရှင်းလင်းသည့်နေရာတွင် [English README](README.md) ကို အတည်ယူပါ။ ပြင်ပေးလိုပါက [docs/TRANSLATING.md](docs/TRANSLATING.md) ကို ကြည့်ပါ။

EinCast သည် macOS နှင့် Windows အတွက် ဒက်စ်တော့ပ်အက်ပ် ဖြစ်သည်။ သင့်ကွန်ပျူတာရှိ မီဒီယာဖိုလ်ဒါတစ်ခုကို အိမ်ရှိ Wi-Fi မှတစ်ဆင့် မျှဝေပေးသဖြင့် တီဗီ၊ iPad နှင့် ဖုန်းများတွင် ဗီဒီယို၊ တေးဂီတနှင့် ဓာတ်ပုံများကို ကြည့်နိုင်သည်။ အင်တာနက်ပေါ်သို့ ဖိုင်များ မတင်ပါ။ အားလုံးသည် သင့်ကွန်ပျူတာပေါ်တွင်သာ ရှိနေသည်။

## ထည့်သွင်းခြင်း

GitHub ရှိ EinCast ၏ Releases စာမျက်နှာမှ သင့်စက်နှင့်ကိုက်ညီသည့်ဖိုင်ကို ဒေါင်းလုဒ်လုပ်ပါ။ အက်ပ်များကို code-sign မလုပ်ရသေးသဖြင့် ပထမအကြိမ်ဖွင့်သည့်အခါ စက်က သတိပေးမည်။ ပုံမှန်ဖြစ်သည်။

- **macOS:** zip ကိုဖြေပြီး Terminal တွင် `xattr -dr com.apple.quarantine eincast.app` ကို ရိုက်ထည့်ပါ။ သို့မဟုတ် အက်ပ်ကို right-click နှိပ်ပြီး ပထမအကြိမ် **Open** ကို ရွေးပါ။
- **Windows:** "Windows protected your PC" ပေါ်လာလျှင် **More info** ကိုနှိပ်ပြီး **Run anyway** ကို နှိပ်ပါ။

## ပထမအကြိမ် အသုံးပြုခြင်း

ပထမအကြိမ်ဖွင့်လျှင် လမ်းညွှန်ပေးမည့် အဆင့်များ ပေါ်လာမည်။

1. **မီဒီယာဖိုလ်ဒါကို ရွေးပါ။** ရုပ်ရှင်၊ သီချင်း၊ ဓာတ်ပုံများ ထည့်ထားသည့် ဖိုလ်ဒါဖြစ်သည်။ ဖိုလ်ဒါများ ထပ်ထည့်လိုပါက Settings → Libraries တွင် ထည့်နိုင်သည်။
2. **ဆာဗာကို စတင်ပါ။** ပထမအကြိမ် စတင်သည့်အခါ ကွန်ပျူတာက network ဝင်ရောက်ခွင့် (firewall) မေးလျှင် ခွင့်ပြုပါ။
3. **စခရင်ပေါ်တွင် ဖွင့်ပါ။** Dashboard ရှိ QR ကုဒ်ကို ဖုန်းဖြင့် စကင်ဖတ်ပါ။ သို့မဟုတ် ပြထားသည့် လိပ်စာကို တီဗီ၊ iPad၏ ဘရောက်ဇာတွင် ရိုက်ထည့်ပါ။

စက်များသည် **တူညီသော Wi-Fi** တွင် ရှိရမည်။ အက်ပ်အသစ်တွင် **access token** ကို ဖွင့်ထားပြီးဖြစ်သည်။ QR ကုဒ်တွင် token ပါဝင်သဖြင့် ၎င်းကို စကင်ဖတ်သည့်ဖုန်းသည် ဝင်ရောက်ပြီးသား ဖြစ်သွားမည်။ တီဗီများသည် token မပို့နိုင်သဖြင့် Settings တွင် **Smart TVs** ကို ဖွင့်လျှင် token ပိတ်သွားမည် (အက်ပ်က အရင်မေးမည်)။

VLC သို့မဟုတ် Infuse တွင် ကြည့်လိုပါက ဖုန်း/တီဗီ၏ ဝက်ဘ်စာမျက်နှာရှိ "VLC / Infuse အတွက် ပလေးလစ်စ်" ခလုတ်ကို သုံးပါ။

## ပြဿနာဖြေရှင်းခြင်း

| ပြဿနာ | စစ်ကြည့်ရန် |
|---|---|
| ဖုန်း/တီဗီမှ မဖွင့်နိုင်ပါ | စက်နှစ်ခုလုံး တူညီသော Wi-Fi တွင် ရှိမရှိ စစ်ပါ။ ဆာဗာ စတင်ထားမထားလည်း ကြည့်ပါ။ Wi-Fi ပြောင်းထားလျှင် Settings → Network ရှိ "Refresh addresses" ကို နှိပ်ပါ။ |
| Wi-Fi တူသော်လည်း မရပါ | ရုံးသုံး/ဧည့်သည် Wi-Fi အချို့တွင် စက်များ တစ်ခုနှင့်တစ်ခု မမြင်ရအောင် ပိတ်ထားသည် (client isolation)။ ကွန်ပျူတာ၏ firewall က EinCast ကို ပိတ်ထားခြင်းလည်း ဖြစ်နိုင်သည်။ Settings → Network တွင် အကြောင်းရင်းများကို စာရင်းပြထားသည်။ |
| `eincast.local` မရပါ | ဖုန်းအချို့သည် ဤအမည်ကို မသိပါ။ အက်ပ်ပြထားသည့် နံပါတ်လိပ်စာ သို့မဟုတ် QR ကုဒ်ကို သုံးပါ။ firewall သည် UDP 5353 နှင့် 1900 ကို ပိတ်ထားလျှင် တီဗီ အလိုအလျောက်ရှာတွေ့ခြင်းလည်း မအောင်မြင်နိုင်ပါ။ |
| ဆာဗာ မစတင်နိုင်ပါ (port သုံးပြီးသား) | Settings → Free a port သည် ထို port ကို မည်သည့်ပရိုဂရမ်က သုံးနေသည်ကို ပြပြီး သင်အတည်ပြုလျှင် ပိတ်ပေးသည်။ |
| ပုံငယ်များ မပေါ်ပါ၊ ဗီဒီယိုအချို့ မပွင့်ပါ | `ffmpeg` ထည့်ထားလျှင် ပုံငယ်များကို ဖန်တီးပေးပြီး MKV/HEVC ကဲ့သို့ ဖိုင်များကို စက်နှင့်ကိုက်အောင် ပြောင်းပေးသည် (ဥပမာ `brew install ffmpeg`)။ Settings → ffmpeg တွင် တွေ့မတွေ့ ပြသည်။ |
| ဖိုင်အမည်များ ဖတ်မရပါ | အောက်ပါ "ဗမာဖိုင်အမည်များ" ကို ကြည့်ပါ။ |

## ဗမာဖိုင်အမည်များ (Unicode နှင့် Zawgyi)

EinCast သည် **Myanmar Unicode** ဖြင့်ရေးထားသော ဖိုင်အမည်များကို ဖိုင်စာရင်း၊ ရှာဖွေခြင်းနှင့် ခေါင်းစဉ်တို့တွင် မှန်ကန်စွာ ပြသည်။ ရှာဖွေရာတွင် စာလုံးရေးသည့်ပုံစံ နှစ်မျိုးရှိသော စာလုံးများ (ဥပမာ ဦ) ကို တူညီသည်ဟု သတ်မှတ်ပေးသည်။

ဖိုင်အမည်ကို **Zawgyi** ဖြင့် ရေးထားလျှင် (အဟောင်းဖုန်းများ၊ အဟောင်းဒေါင်းလုဒ်များတွင် ဖြစ်တတ်သည်) စာလုံးများ ထပ်နေခြင်း သို့မဟုတ် အစီအစဉ်မှားနေခြင်း ပေါ်နိုင်သည်။ EinCast သည် Zawgyi ကို အလိုအလျောက် မပြောင်းပါ။ ပြင်လိုပါက ဖိုင်ကို Zawgyi-to-Unicode ပြောင်းကိရိယာဖြင့် အမည်ပြောင်းပြီး ကွန်ပျူတာတွင် Unicode အမည်ဖြင့် သိမ်းပါ။ ထို့နောက် EinCast သည် ဖိုလ်ဒါကို ကိုယ်တိုင် ပြန်စစ်သည် (မပြောင်းလျှင် Library စာမျက်နှာတွင် rescan လုပ်ပါ)။
