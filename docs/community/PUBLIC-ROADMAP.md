## What is coming next

**Now: making it adoptable (v1.1.x)**
- Real-device checks: iPhone, iPad, Safari, a smart TV, VLC, Infuse
- Code signing for macOS and Windows, so the first-launch warning goes away
- Burmese review by a native speaker
- Package managers: Homebrew, winget, Scoop (after signing)

**Next: if people ask**
- Optional movie posters and descriptions from the internet (TMDB), off by default, with your own key
- A headless mode (`eincastd`) for a NAS, Raspberry Pi or Docker
- Seeking ahead while a video is still converting
- More languages, from the community

**Not planned, on purpose**
Accounts, a cloud service, analytics, a plugin system, live TV and recording, a mobile app.

## How to help decide

React 👍 to what you want most, or add an idea in *Ideas* (it helps to say *what you are trying to do*, not only
what to build). The maintainer reads everything and decides; EinCast stays simple.
