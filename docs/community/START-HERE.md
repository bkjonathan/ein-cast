## GitHub Discussions: "Start here" (English)

**Welcome to EinCast: your home media, on every screen.**

EinCast turns a folder on your Mac or Windows PC into a media server for the TVs, tablets and phones at
home. No accounts, no cloud.

- **Download:** https://github.com/bkjonathan/ein-cast/releases/latest (builds are not code-signed yet, so
  your system warns the first time: the README says how to open it)
- **First time?** Choose a folder, scan the QR code with a phone, press play. The README has the steps.
- **Something is wrong?** In EinCast: Settings → Help and feedback → *Copy diagnostics*, then open a
  [bug report](https://github.com/bkjonathan/ein-cast/issues/new?template=bug_report.yml) and paste it. Read it first.
- **Tried it on a TV or player?** Tell us what worked and what did not: it is the most useful thing you can do
  ([device list](https://github.com/bkjonathan/ein-cast/blob/main/docs/TESTING-DEVICES.md)).
- **Ideas:** post them under *Ideas*. EinCast stays simple on purpose (no accounts, no cloud, no plugins).
- **Help build it:** [CONTRIBUTING.md](https://github.com/bkjonathan/ein-cast/blob/main/CONTRIBUTING.md). Translators and
  Burmese reviewers are especially welcome.

Please be kind: [code of conduct](https://github.com/bkjonathan/ein-cast/blob/main/CODE_OF_CONDUCT.md). EinCast plays files you
already have; we do not help find pirated content.

Suggested categories: **Announcements** (maintainer only), **Q&A**, **Ideas**, **Show and tell** (your setup,
your TV), **Device reports**.

## မြန်မာ (Facebook / Telegram / Discussions)

**EinCast မှ ကြိုဆိုပါသည်: သင့်အိမ်ရှိ မီဒီယာများကို ဖန်သားပြင်တိုင်းတွင်။**

EinCast သည် သင့် Mac သို့မဟုတ် Windows ကွန်ပျူတာရှိ ဖိုလ်ဒါတစ်ခုကို အိမ်ရှိ တီဗီ၊ တက်ဘလက်၊ ဖုန်းများသို့ မျှဝေပေးသော အက်ပ်ဖြစ်သည်။ အကောင့်မလို၊ cloud မလို။

- **ဒေါင်းလုဒ်:** https://github.com/bkjonathan/ein-cast/releases/latest (လက်မှတ်ထိုးထားခြင်း မရှိသေးသဖြင့် ပထမအကြိမ် ဖွင့်ချိန် သင့်စနစ်က သတိပေးပါမည်။ README တွင် ဖွင့်နည်း ရှိသည်)
- **ပထမဆုံးအကြိမ်လား?** ဖိုလ်ဒါရွေးပါ၊ ဖုန်းဖြင့် QR ကုဒ်ကို စကင်ဖတ်ပါ၊ ကြည့်ပါ။
- **ပြဿနာရှိလား?** EinCast ထဲတွင် Settings → အကူအညီနှင့် အကြံပြုချက် → "ရောဂါရှာဖွေရေး အချက်အလက် ကူးယူရန်" ကိုနှိပ်ပြီး ဤနေရာတွင် (သို့) GitHub တွင် ကပ်ပေးပါ။ မတင်မီ ကိုယ်တိုင် ဖတ်ကြည့်ပါ။
- **သင့်တီဗီ သို့မဟုတ် ဖုန်းတွင် စမ်းကြည့်ပြီးပြီလား?** အလုပ်လုပ် / မလုပ်ကို ပြောပြပါ။ ဤအကူအညီသည် အလွန်တန်ဖိုးရှိသည်။
- **မြန်မာစာ ပြန်ဆိုချက်ကို ပြင်ပေးလိုပါသလား?** ကျွန်ုပ်တို့၏ ပြန်ဆိုချက်သည် မူကြမ်းသာ ဖြစ်သဖြင့် ဗမာစကားပြောသူ၏ ပြင်ဆင်ချက်များကို အထူးကြိုဆိုပါသည်။

ကျေးဇူးပြု၍ ယဉ်ကျေးစွာ ဆက်ဆံကြပါ။ EinCast သည် သင့်တွင် ရှိပြီးသား ဖိုင်များကိုသာ ကစားပေးသည်။ ခိုးကူးဖိုင် ရှာပေးခြင်း မလုပ်ပါ။
